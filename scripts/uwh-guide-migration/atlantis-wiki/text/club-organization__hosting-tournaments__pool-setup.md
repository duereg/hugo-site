# *Pool Setup

- URL: https://wiki.atlantissports.org/club-organization/hosting-tournaments/pool-setup
- Path: `club-organization/hosting-tournaments/pool-setup`

¶ Description

During tournaments, there is some extra setup required beyond what is normally used during practices. The following things are needed for the [/game/gear-setup/courts] court:

 
 [/game/gear-setup/goals] Goals- It is best if there are full sized goals that meet all the regulations. If clubs do not own their own set of goals, they should reach out to other clubs nearby to see if they could be borrowed and shipped over for the weekend.

 
 [/game/gear-setup/walls] Barriers/Walls- The playing area should be marked out by solid barriers wherever there is not a pool wall. There are several methods of doing this, and the method differs depending on what the pool bottom is like.

 
Sub boxes- These should be set up right next to the court. This is usually done by putting two lane ropes in next to the playing area and then stringing pool noodles across the lane lines, marking out two subbing areas.

 
Ref table- This table should be set up on the opposite side of the playing area as the sub boxes. This is where the score should be displayed and the chief referee will be standing beside this table.

 
 [/game/gear-setup/buzzers] Buzzer- Buzzer systems can be rented. They consist of an underwater speaker and sometimes also an above water speaker. Different sounds can be used for each playing area at tournaments with more than one court. A cheaper system that clubs can also get is a metal bar that is hung half way into the water. This is hit with another bar to make a sound. This should in general not be used if there is more than one playing area, as it is hard to distinguish which clanging bar is for which playing area.
