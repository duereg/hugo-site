# Fins

- URL: https://wiki.atlantissports.org/game/gear-setup/fins
- Path: `game/gear-setup/fins`

¶ Description

Players always wear fins when playing. Fins can range in size from small swim fins to long diving fins, depending on the individual’s preference. Fins make it much easier to maneuver with the puck and speed up the game significantly. The fins should not have buckles or any metal.
