# Practices

- URL: https://wiki.atlantissports.org/club-organization/practices
- Path: `club-organization/practices`

¶ Description

Running practices that are fun and useful for all players is not a simple task. All pools have slightly different set-ups and players have different priorities. To make the best of each practice, clubs will have to determine what they want to spend their time in the pool doing and develop protocols to keep things running smoothly.
