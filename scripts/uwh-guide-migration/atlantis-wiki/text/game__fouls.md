# Understanding Fouls

- URL: https://wiki.atlantissports.org/game/fouls
- Path: `game/fouls`

¶ Description

There are many things in underwater hockey that are not allowed during game play. This section covers all the types of fouls that can be called in a game. 

There is a lot to remember when it comes to fouls, and players may not always understand what they did wrong. If this is the case, simply keep playing and once the game has finished, approach the referee that called the foul ask for clarification about what happened.
