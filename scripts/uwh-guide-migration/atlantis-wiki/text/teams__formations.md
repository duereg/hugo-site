# Formations

- URL: https://wiki.atlantissports.org/teams/formations
- Path: `teams/formations`

¶ Description

All Formations have strengths and weaknesses and how they match up against an opposing team's formation is one of the things that makes this sport so interesting to play. Additionally, just because a team orients their players in a similar pattern does not mean they have the same strategies, they can play completely different style games!

Below are some of the more common formations. The naming convention describes first the number of offensive leaning players then the number of defensive players. Some formations have 3 or more layers but still describe the number of offensive leaning players first and number of defensive players players last, with other roles that may have split responsibilities counted in between.
