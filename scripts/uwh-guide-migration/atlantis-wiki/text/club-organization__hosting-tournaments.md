# Hosting Tournaments

- URL: https://wiki.atlantissports.org/club-organization/hosting-tournaments
- Path: `club-organization/hosting-tournaments`

¶ Description

Hosting tournaments is a great way for clubs to expand and can increase excitement and involvement in the sport. Tournaments can also help clubs get more money, which can allow for more growth and development of the team in the future. There is a lot that goes into hosting a tournament, and it can be quite difficult. This section includes and overview of all that needs to be done for hosting a tournament, and some tips and tricks that can make things easier.
