# *Time/Score Displays

- URL: https://wiki.atlantissports.org/game/gear-setup/time-score_displays
- Path: `game/gear-setup/time-score_displays`

¶ Description

Along the side of the courts there is a ref table at which the score and timing displays are set up. This is also where the chief referee stands. It is possible that only the scores will be displayed to the players, but often the score, time, penalties, and timeouts will all be displayed to the players.
