# *Passing Circles

- URL: https://wiki.atlantissports.org/teams/teamwork_drills/passing-circle
- Path: `teams/teamwork_drills/passing-circle`

¶ Description

A passing circle is much as it sounds, players set up in a circle and simply [/players/individual_fundamentals/puck_handling/passes/flicks_full_motion] pass the [/game/gear-setup/pucks] puck around the circle. This is a great way to warm up the wrist before a game. Passing circles can have some variations that work on different skills.

 
Pass the puck quickly form one person to the other.

 
Do a few movements with the puck before passing it.

 
Pass the puck to the next person's hip and they will [/players/evasive_maneuvers/standard_curl] curl as they pick it up, then [/players/individual_fundamentals/puck_handling/passes/flicks_full_motion] flick it to the next person straight out of their curl.

 
Have several pucks traveling around the circle, some in opposite directions.
