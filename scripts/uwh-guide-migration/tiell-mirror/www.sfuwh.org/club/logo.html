Logo

In 2009 we decided it would be nice to have a banner for the club. There was a huge email discussion as various ideas were offered and critiqued. The end result was a nice banner created by the very talented Mac Borcz (maciejborcz.com) and a charter with official club leadership responsible for making decisions without consulting everyone else.


We have adapted Mac's design for a few other purposes such as the website logo. If you make something from it please upload the source here. You can read and edit svg files using the free Inkscape editor available for Windows, Mac and Linux. Inkscape can also read pdf files and export to almost any format.


Here is the old logo which we used for roughly 2000(?) to 2009. It is based on a design done long ago by a t-shirt company.
